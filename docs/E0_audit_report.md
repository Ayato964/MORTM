## E0-7: META 実内容の全数目録化（v1.6 恒久ルール）  ✅
A1 基盤 19,824 META(SYSTEM..TAG_END) ブロックを走査、属性トークンを名前接頭辞で分類:

| META 内属性 | 出現率 | 分析タスクでの扱い(E0-7 ルール: 目録外は使用禁止) |
|---|---|---|
| instrument | 100% | 構造(常時条件)。分析標的ではない |
| **key** | **100%** | **唯一の主分析指標**(v1.6) |
| **density** | **100%** | 従指標 |
| length(GMC/小節数) | **0%（不在）** | **除外**。基盤 `make_system_prompt` は call_function 無しで呼ばれ GMC 非付与(GMC は SFT のみ)。→ genre と同理由で分析標的として無効 |
| genre | **0%（不在）** | 除外(E3-X のみ)。ジャンル事案の確認 |
| chord | **0%（不在）** | chord 分析は**追加しない**。key を唯一主指標とし Limitations 明記(E0-7) |

**★E0-7 の帰結(裁定 A で確定, 2026-07-12)**: 目録の実測で **length(小節数) も基盤 META に不在**。
E0-7 恒久ルール(目録外禁止)を厳格適用し **length を分析スイートから除外**(ユーザ裁定 A)。
→ **有効な分析属性 = key(主指標) + density(従指標) の 2 つのみ**。chord/genre/length は除外。
Limitations に「基盤 META は instrument/density/key のみを含み、分析評価はこの 2 属性に限定」と明記する。

## E0-6: タグ・終端仕様（CONST削除の偽隣接リスク, v1.4）  ✅(仕様確認)
ブロックタグ(`<PAST_M>/<FUTURE_M>/<CONST_M>/<TAG_END>`)は**スパン/ギャップ情報を持たない**単純マーカー。
CONST 削除サンプルは隠れギャップを挟む [PAST][FUTURE] を隣接提示するため**偽の時間的隣接**を教える懸念あり
(§3.4 副次リスク)。対策: A3b で監視(E1)。恒久的な仕様変更は本論文スコープ外。
